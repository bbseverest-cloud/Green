# IGBC Green Schools – Lead Generation Poster

A3 portrait (297 × 420 mm) poster inviting educational institutions to pursue the IGBC Green Schools rating.

- `igbc-green-schools-poster.pdf` – print-ready A3 PDF
- `igbc-green-schools-poster.png` – high-resolution image (3369 × 4764 px) for social media / email
- `poster.html` – editable source (uses `assets/` logos and Google Fonts: Poppins, Merriweather)

To re-export after editing, open `poster.html` in Chrome and print to PDF at A3 with background graphics enabled, or render it with Playwright.

# IGBC Green Interiors – Digital Promotion Poster

4:5 portrait (1080 × 1350 px) poster for social media, WhatsApp, email and web, promoting the IGBC Green Interiors rating.

- `igbc-green-interiors-poster.png` – 2× resolution image (2160 × 2700 px) for sharing online
- `igbc-green-interiors-poster.pdf` – single-page PDF of the same design; the email address is a clickable link that opens a pre-filled draft
- `green-interiors-poster.html` – editable source (uses `assets/` logos and Google Fonts: Fraunces, Plus Jakarta Sans)

To re-export, render `green-interiors-poster.html` with Playwright at a 1080 × 1350 viewport and `deviceScaleFactor: 2`.

# IGBC Green Interiors – Promotional Email (EDM)

Folder `edm/`:

- `green-interiors-edm.html` – email-ready HTML (600 px, table layout, inline styles, stacks on phones, Outlook-safe button). Paste or import it into your email tool as custom HTML.
- `email-copy.md` – subject lines, preheader, plain-text version, and LinkedIn/WhatsApp posts that link to the web version
- `images/` – images the email loads from this GitHub repository
- `web/index.html` – the "view in browser" page, generated by `python3 edm/build-web-version.py`
- Web version: https://claude.ai/artifact/AuY2xefZMx15hxCS5ygoEP (set sharing to "anyone with the link" before sending)

The email loads images from `raw.githubusercontent.com/.../claude/friendly-hypatia-tyb65z/`. If this branch is merged or deleted, replace that path with `main` (or your own image host) in both HTML files.
