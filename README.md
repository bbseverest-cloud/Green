# IGBC Green Schools – Lead Generation Poster

A3 portrait (297 × 420 mm) poster inviting educational institutions to pursue the IGBC Green Schools rating.

- `igbc-green-schools-poster.pdf` – print-ready A3 PDF
- `igbc-green-schools-poster.png` – high-resolution image (3369 × 4764 px) for social media / email
- `poster.html` – editable source (uses `assets/` logos and Google Fonts: Poppins, Merriweather)

To re-export after editing, open `poster.html` in Chrome and print to PDF at A3 with background graphics enabled, or render it with Playwright.
